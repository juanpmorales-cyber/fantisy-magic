# Fantasy Magic

A browser game made with HTML, CSS and JavaScript.

## Run locally
Double-click `index.html` or open it with Chrome/Edge.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js`.
3. Open Settings -> Pages.
4. Set Source to **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will give you a playable web address.

Controls: WASD/Arrow Keys, Shift, Mouse, Left Click. Press R after dying.
